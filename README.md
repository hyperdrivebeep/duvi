# Duvi · 듀비

영어와 한국어 자막을 함께 보며 강의를 공부하는 로컬 웹앱입니다. MIT OpenCourseWare와 YouTube 강의를 한 라이브러리에서 재생하고, 문장별 이동·반복·자동 멈춤·이어보기를 지원합니다.

## 학습 도구로의 발전 계획

첫 학습 순서는 기존 **MIT Python 기초의 Lecture 1 → 2 → 3**입니다.
[학습·탐구 기획](docs/LEARNING_DESIGN.md)은 강의에서 생긴 질문을 근거·가정·대안·판별 실험·생각 수정으로 연결합니다. 연결된 강의별 로드맵에 첫 2주 일정과 단계별 실습을 정리했습니다. **새 학습 카드와 복습 기능은 기획 단계이며 아직 구현되지 않았습니다.**

## 실행

현재 전체 기능은 **Windows + Node.js 24 이상**에서 지원합니다. ChatGPT 인증 정보 보관에는 Windows DPAPI를 사용합니다.

```powershell
npm ci
npm run setup -- --youtube
npm run build
npm start
```

[플레이어 열기](http://127.0.0.1:6103). 준비가 끝난 뒤에는 `Start-Study.vbs`를 실행해 서버와 브라우저를 열 수 있습니다.

`setup`은 MIT 공식 서버에서 26개 강의의 영어 자막을 받아 준비합니다. 기존 자막 파일은 덮어쓰지 않습니다. `--youtube` 옵션은 Windows용 yt-dlp를 고정된 공식 릴리스에서 내려받고 SHA-256을 확인합니다. 영상 파일은 내려받지 않습니다. MIT 강의만 이용하려면 옵션 없이 `npm run setup`을 실행하세요.

## 사용

- **새 폴더**로 강의를 주제별로 묶습니다. 폴더 이름을 눌러 접거나 펼치고,
  오른쪽 메뉴에서 이름 변경·폴더 삭제를 할 수 있습니다. 기존 MIT 강의는
  ‘MIT Python 기초’ 폴더에 모입니다.
- **재생목록 추가**에 YouTube 재생목록 공유 주소를 붙여넣으면 제목과 원래
  영상 순서를 가져옵니다. 기본값은 재생목록 제목의 새 폴더이며, 기존 폴더도
  선택할 수 있습니다. 최대 500개까지 지원하고 다시 가져오면 기존 강의를 재사용합니다.
- 재생목록의 영어 자막은 강의를 처음 열 때 준비합니다. 자막 요청이 제한되면
  **영어 자막 다시 가져오기** 또는 **영어 자막 파일 추가**로 보완할 수 있습니다.
  자막이 없어도 영상을 재생할 수 있으며, 비공개·삭제 영상은 원본 확인 상태로 표시합니다.
- 강의 오른쪽 이동 버튼으로 폴더를 바꿀 수 있습니다. 폴더 삭제는 강의·자막·번역을
  지우지 않습니다. 다른 폴더에 속하지 않은 강의는 ‘미분류’에 표시됩니다.
- 폴더 이름과 강의 순서는 `backend/library/folders.json`에 저장됩니다.
  다른 PC로 옮길 때 `backend/library/`와 `backend/translations/`를 함께 백업하세요.

- 왼쪽 라이브러리에서 강의를 검색하고 선택합니다.
- **강의 추가**에서 YouTube 영상 주소를 등록합니다. 영어 자막을 가져올 수 없다면 SRT/VTT 파일(2MB 이하)을 보완할 수 있습니다.
- **설정**에서 ChatGPT 계정을 연결하고, **번역 상태**에서 모델과 5분/전체 번역 범위를 선택합니다. 계정에서 제공하는 접근 권한과 사용 한도가 적용됩니다.
- 번역 요청은 영어 자막과 앞뒤 문맥을 OpenAI로 보냅니다. 완료한 번역은 PC에 저장하며 다시 재생할 때 재사용합니다. 중단 후에는 미완료 구간을 이어서 처리합니다.
- Chrome 기기 내 번역을 선택할 수도 있습니다. 브라우저의 Translator API 지원과 언어 모델 준비가 필요합니다.
- 입력창과 대화상자 밖에서 `←`/`→` 문장 이동, `R` 반복, `F` 전체화면을 사용합니다.
- **자막 전체화면**은 영상 아래에 영어·한국어를 표시합니다. 각 언어는 최대 두 줄을
  온전히 보여 주며 긴 문장은 스크롤할 수 있습니다. 두 언어 사이 간격은 12px입니다.
- 전체화면의 **⚙**에서 자막 위치(영상 아래/영상 위 상단/하단)와 크기를 바꾸고,
  **대본**을 열 수 있습니다. 조작 버튼은 자동으로 숨겨지며 종료 버튼과 `Esc`를 지원합니다.

## 다른 컴퓨터에서 사용하기

Windows와 Node.js 24 이상을 준비하고, 새 컴퓨터에서 다음을 실행합니다.

```powershell
git clone https://github.com/hyperdrivebeep/duvi.git
cd duvi
npm ci
npm run setup -- --youtube
npm run build
npm start
```

이미 저장소가 있다면 실행 중인 Duvi 서버를 종료한 뒤 `git pull --ff-only`,
`npm ci`, `npm run build`, `npm start` 순서로 업데이트합니다.
실행 중인 서버는 코드 변경만으로 새 번역 처리 코드를 다시 읽지 않으므로 재시작이 필요합니다.

**코드와 개인 학습 데이터는 별도로 옮깁니다.** GitHub만 복제하면 추가한
강의 폴더와 저장된 한국어 번역은 따라오지 않습니다. 기존 PC의 다음 폴더를
새 PC 저장소의 같은 경로로 복사하세요. 새로 복제한 저장소에 복원하는 것을 권장합니다.

- `backend/data/`: MIT 강의의 영어 원문
- `backend/library/`: 추가 강의·영어 자막·폴더와 강의 순서
- `backend/translations/`: 문장별 한국어 번역과 맞춰진 영어 문장

`backend/` 폴더 구조를 유지한 데이터 ZIP이 있다면 새 저장소에서
`Expand-Archive -LiteralPath "C:\경로\duvi-data.zip" -DestinationPath .`로 복원합니다.
이미 학습 데이터가 있는 PC에서는 먼저 기존 데이터를 백업하고 같은 이름의 파일을 확인하세요.
영상 파일은 포함되지 않으며 원본 서비스에서 스트리밍합니다.

ChatGPT 연결은 새 PC에서 다시 로그인합니다. 브라우저에 저장된 재생 위치,
자막 표시 설정과 Chrome 기기 내 번역은 위 파일 백업에 포함되지 않습니다.
저장된 ChatGPT 번역은 로그인 없이 읽을 수 있습니다. 두 PC 사이에 자동 동기화는 없습니다.

## 구조와 저장 위치

```text
브라우저 UI (Vite로 빌드한 일반 JavaScript)
  ├─ MIT HTML video / YouTube IFrame Player
  └─ 같은 주소의 Node.js API
       ├─ 강의·영어 자막 관리
       ├─ ChatGPT 인증 및 문맥 번역
       └─ 강의별 JSON 저장
```

| 위치 | 내용 | Git 포함 |
| --- | --- | --- |
| `src/` | 화면, 재생·자막 동기화 | 예 |
| `backend/` | 로컬 API, 로그인, 번역 코드 | 예 |
| `backend/data/` | 설치 시 준비하는 MIT 영어 자막 | 아니요 |
| `backend/library/` | 사용자가 추가한 강의·자막 | 아니요 |
| `backend/translations/` | 저장한 AI 번역 | 아니요 |
| `%LOCALAPPDATA%/StudyLibraryPreview/` | DPAPI로 암호화한 인증 정보 | 아니요 |

서버는 `127.0.0.1:6103`에만 바인딩합니다. 인증 토큰은 브라우저로 전달하지 않습니다. 학습 데이터·번역·로그·빌드 결과·node_modules는 저장소에서 제외됩니다. 다른 PC에서 저장한 번역을 사용하려면 데이터 폴더를 별도로 백업·복원하세요. 인증 정보는 해당 PC에서 로그인해 준비하세요.

## 영어·한국어 문장 맞추기

ChatGPT의 **전체 강의 번역**은 시간 단위로 잘린 원문을 완결된 문장/절로
다시 나누고, 같은 범위의 한국어를 한 쌍으로 저장합니다. 원문 단어의 순서와
누락 여부를 검증하며, 화면·전체 대본·문장 이동·반복 재생에 같은 경계를 사용합니다.
기존 번역은 완료 전까지 유지하고 완료 시 별도 백업합니다. 중단한 작업은
다시 전체 강의 번역을 누르면 이어서 처리합니다. 5분 시험 번역은 기존 구간을
번역하며, 문장 맞추기가 완료된 강의에서는 새 문장 경계를 사용합니다.

원본에 단어별 시간이 없으면 기존 자막 구간 안에서 단어 길이로 시간을
추정하므로 음성과 문장 전환에 약간의 차이가 있을 수 있습니다. 이미 가져온
강의를 서버 재시작 없이 정리하는 관리 명령은
`node scripts/align-captions.mjs 강의_ID 모델_ID`입니다.

## 검증

```powershell
npm test
npm run build
```

인증/PKCE, 토큰 검증, 번역 응답·중단·재개, 자막 파싱, HTTP 요청 보호, 재생 위치 복원 등을 검사합니다. 실제 브라우저 검증 범위와 미검증 항목은 [TEST-RESULTS.md](TEST-RESULTS.md)에 기록합니다.

## 자료 출처와 제한

MIT 영상과 영어 자막은 [MIT OpenCourseWare](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/)가 제공합니다. 해당 자료의 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 조건이 적용됩니다. 이 저장소에는 강의 자료 자체 대신 공식 출처 목록과 설치 스크립트를 넣습니다.

YouTube 영상·자막의 권리는 각 권리자에게 있습니다. 자막을 가져올 수 없는 영상과 외부 재생이 제한된 영상은 지원하지 못할 수 있습니다. 한국어 자막은 AI 번역이며 정확성을 보증하지 않습니다. 외부 의존성의 출처와 라이선스는 [THIRD-PARTY.md](backend/THIRD-PARTY.md)를 참고하세요.

전체 기능에는 로컬 Node 서버가 필요합니다. 포함된 Sites 템플릿만 정적으로 배포하면 로그인·가져오기·번역이 동작하지 않습니다.
