## 공개 기준

- 이 저장소는 공개 저장소입니다. 올리기 전에 모든 이미지를 글자 인식(Windows OCR)과 눈으로 검사했고, PC 이름과 사용자 이름이 들어간 로컬 경로가 보이던 13장은 해당 부분을 회색 상자로 가렸습니다. 텍스트·JSON 파일의 로컬 경로는 `<qa-work>/`, `<user-home>`으로 바꿨습니다.
- 화면의 학습 기록은 QA가 만든 예시 질문이고, 채팅 답변은 모의 공급자(`DUVI_CHAT_MOCK=1`)의 문장입니다. 실제 학습자의 기록, 계정, 토큰, 강의·번역 데이터, 원시 로그는 넣지 않았습니다.
- 공개 강의 영상(MIT 6.100L, Andrej Karpathy의 micrograd 강의)의 프레임이 화면 배치 증거로 작게 들어 있습니다.
- 원본 PNG는 WebP(최대 너비 1600px, 품질 80)로 바꿔 저장소를 작게 유지했습니다.

## 공통으로 확인하지 않은 것

- 진짜 브라우저 전체화면을 실제 Esc 키로 빠져나오는 동작 (2026-11-19-how-to-study에서 실제 Esc 키 이벤트로 창 채우기 모드 종료는 확인했지만, 그 창에서는 Chrome이 진짜 전체화면을 거부함)
- 물리적으로 다른 두 PC (동기화는 같은 PC의 서로 격리된 두 상태로만 확인)
- 실제 ChatGPT 답변의 품질 (`DUVI_CHAT_MOCK=1` 모의 공급자만 사용)
- 강의 영상 내용 자체 (영상 프레임은 화면 배치를 보여 주는 작은 증거 사진일 뿐입니다)
