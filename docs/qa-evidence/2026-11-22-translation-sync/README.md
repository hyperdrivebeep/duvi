# PC A에서 만든 한국어 자막을 PC B에서 열기

공개 MIT 6.100L 1강의 도입부 네 문장으로 확인했습니다. 한 Windows 컴퓨터에서 Duvi 서버 두 개를 다른 포트로 실행하고, 각 서버에 별도의 강의·번역·학습 데이터 폴더와 `LOCALAPPDATA`를 주었습니다. 같은 임시 동기화 폴더만 두 앱에서 선택했습니다. 기기 이름과 번역은 시연용입니다. 실제 계정이나 AI 호출은 사용하지 않았습니다.

1. B에서 00:16의 영어 인사말을 열었습니다. 한국어 칸에는 아직 번역하지 않았다는 안내가 나왔습니다. [가져오기 전](01-before.webp)
2. A에만 저장한 문장 맞춤 번역을 백업·동기화 화면에서 내보냈습니다. 강의 파일 하나가 1,234바이트였습니다. B에서 다시 찾기와 미리보기를 누르자 한국어 번역 **새로 1강**이 표시됐습니다. 화면에서 개인 폴더 경로를 제외하고 미리보기 부분만 잘랐습니다. [합치기 미리보기](02-preview.webp)
3. 확인란에 체크하고 합친 뒤 B에서 같은 강의를 다시 열었습니다. 같은 문장에 **“애나 벨: 6.100L 첫 강의에 오신 것을 환영합니다.”**가 나왔고, 번역 상태는 4/4문장이었습니다. [가져오기 후](03-after.webp)
4. B에서 전체화면 버튼을 눌렀습니다. `document.fullscreenElement.id`가 `stage`, 브라우저 안쪽 크기가 1536×864였으며 같은 한국어가 영상 아래 표시됐습니다. [브라우저 전체화면](04-fullscreen.webp)

캡처 네 장에서 개인 경로·계정·학습 기록이 보이지 않는 것을 확인했습니다. 실제 두 컴퓨터 간 이동, OneDrive 전송 지연·잠금은 확인하지 않았습니다.
