## 1. 제1원칙 분해: 모델 설계는 무엇으로 이루어지나

1. **모델 = 조절 손잡이(파라미터)가 달린 함수.** 같은 식이라도 손잡이 값이 다르면 다른 예측을 한다 (d2l 1.2).
2. **학습 = 데이터로 손잡이 값을 고르는 일.** "얼마나 틀렸나"(손실)를 정하고, 그 값이 줄어드는 쪽으로 손잡이를 돌린다.
3. 그러려면 여섯 가지가 필요하다: 함수가 어떻게 변하는지(**미적분**), 수많은 손잡이를 한꺼번에 계산하는 법(**선형대수**),
   무엇을 얼마나 확신하며 맞추는지(**확률**), 실제로 돌리는 법(**코드**), 어떤 가정을 구조에 넣는지(**아키텍처**),
   정말 나아졌는지 판단하는 법(**평가**).
4. 이 프로젝트의 모델은 그 위에 "측정 집합을 읽는 신경망 앙상블 + 공식 탐색과 베이즈 모델 평균 + 실험 선택"을 얹는다(**프로젝트 전용**).

## 7. 신경망 핵심 (사용자가 짚은 빈칸)

| 개념 | 제1원칙 설명 | 설계에서 왜 필요 | 수준 |
|---|---|---|---|
| **가중치** | 입력에 곱하는 학습되는 숫자 하나. 크면 그 입력이 출력을 세게 밀고, 음수면 반대로, 0 근처면 무시. 가중치 행렬은 입력 벡터를 출력 벡터로 바꾸는 학습된 선형 변환 | 학습이 바꾸는 것은 가중치뿐; 구조를 바꾼다는 것은 가중치가 몇 개이고 무엇을 잇는지 정하는 일. 우리 캐시가 state_dict(가중치)만 저장해도 동작이 복원됨(AE:219-224) | ① |
| **편향** | 가중합 뒤에 더하는 학습되는 숫자. 입력이 모두 0이어도 출력이 편향값 | 원점 강제를 풀어 줌; `bias=False`도 설계 선택 | ① |
| **파라미터와 세기** | 가중치+편향. nn.Linear(in,out) = in×out + out | 코드만 보고 크기 예측. 우리 모델: Attention q,k,v,o 66,048 + 블록 132,480 ×4 + 입력·토큰·헤드 = **531,714**, ×3 = 1,595,142 | ① |
| 뉴런 | z = Σwᵢxᵢ + b, 그다음 비선형 함수 | 층 = 같은 입력을 읽는 뉴런 여러 개 | ① |
| 활성화 함수(ReLU·sigmoid·tanh·GELU) | 가중합을 구부리는 고정 함수 | 비선형이 없으면 깊이가 무의미; 포화하면 기울기 소실 | ① |
| MLP·은닉층·폭·깊이 | 완전연결 층을 쌓음 | 첫 설계 손잡이; 우리 블록의 MLP는 2배 확장(AE:71-72,80-81) | ① |
| 보편 근사 정리 | 충분히 넓으면 근사할 가중치가 **존재**함(찾을 수 있다는 보장 아님) | "넓은 한 층이면 다 된다"는 오해 차단 | ② |
| 순전파·계산 그래프 | 값을 계산하며 각 연산이 입력을 기억 | 어떤 경로로 기울기가 흐르는지(detach, 마스크) | ① |
| **역전파 (손계산 예제)** | f=(w₁x₁+w₂x₂+b−y)², x₁=2, x₂=−1, y=2, w₁=0.5, w₂=1, b=0.5 → f=2.25. 국소 기울기 df/de=2e=−3을 경로마다 곱해 df/dw₁=−6, df/dw₂=+3, df/db=−3. 수치 검사 −5.996. 학습률 0.1로 한 걸음 → f=0.09 | 옵티마이저가 쓰는 "기울기"가 정확히 이 숫자; 갈래에서는 기울기를 **더함** | ① |
| 역방향 자동 미분·위상 순서 | 손실에서 한 번 거꾸로 훑어 모든 파라미터 기울기를 얻음 | 160만 개 가중치 학습이 가능한 이유 | ② |
| 기울기 누적·zero_grad | .grad는 더해지므로 비워야 함 | 우리 코드는 autograd.grad라 누적 없음 | ① |
| 학습은 가중치를 바꾸고 추론은 안 바꿈 | 추론 때는 순전파만 | 우리 NP는 새 측정을 **맥락**으로 받아 적응(AE:166-177) | ① |
| 초기화(Xavier/He)·대칭 깨기 | 같은 값으로 시작하면 영원히 같은 뉴런; 분산 유지되는 크기 | fan-in이 초기화 범위를 정함(AE:130); 폭을 바꾸면 범위도 바뀜 | ① |
| 기울기 소실·폭발 | 층마다 곱해져 0이나 무한대로 | 초기화·정규화·잔차·클리핑의 존재 이유 | ① |
| 배치 정규화 vs 층 정규화 | 배치 통계로 / 예제 하나의 특징으로 정규화 | 우리는 층 정규화만 사용; 배치 정규화의 원리는 쟁점(아래) | ①(층), ③(배치 원리) |
| 잔차 연결 | 출력 = x + F(x), 수정분만 배움 | 깊게 쌓아도 학습됨; shape이 같아야 함 | ① |
| 드롭아웃·가중치 묶기 | 무작위로 끄기 / 같은 행렬을 두 곳에 | 우리 코드에는 둘 다 없음 | ② |
| 평균+로그분산 출력층 | 출력 2개(평균, log σ²), 로그로 양수 보장, 범위 제한 | 우리 헤드(AE:96,141,183) | ① |
| 마스크 | 없는 측정을 −1e9로 가려 softmax에서 제외 | 세계마다 측정 수가 다름(AE:56, NE:74-75); 전부 가려진 행은 균등 평균이 됨(점검 거리) | ① |
| 입력·목표 스케일링, 잔차 목표 | log L, log m, θ, θ² 특징; 교과서 대비 차이를 ×10으로 예측 | NE:24-27, NE:16, AE:104,139,182 | ① |

## 8. 아키텍처: 구조에 어떤 가정을 넣나

**주 경로(이 프로젝트):** 귀납 편향 → 불변·등변 → 집합(Deep Sets) → 평균 풀링은 정보를 잃음(우리 기록,
ARCHITECTURE_STUDY_GUIDE.md:115; NE:105-106) → Attention(Q·K·V, 자기/교차, 멀티헤드) → Transformer 블록
(Attention + MLP + 잔차 + 층 정규화) → Neural Process → Attentive NP → 앙상블.

| 개념 | 한 줄 정의 | 설계에서 왜 필요 | 수준 |
|---|---|---|---|
| 귀납 편향 | 데이터를 보기 전에 구조가 넣는 가정 | 모든 설계의 첫 질문; 작은 데이터에서는 크기보다 중요 | ① |
| 불변 vs 등변 | 변환해도 출력 그대로 / 출력도 같이 변환됨(f(g(x))=g(f(x))) | "중간 층은 등변, 마지막 읽기는 불변"; 우리 모델은 측정 순서를 바꿔도 출력 변화 3.9e-07 | ① |
| 순열 불변·Deep Sets | 순서 없는 집합은 ρ(Σφ(xᵢ)) 꼴 | NP 맥락 인코더의 원형; 위치 정보를 넣으면 안 됨 | ① |
| Q·K·V Attention | 질의와 열쇠의 유사도로 값의 가중 평균 | ANP에서 목표 x가 질의, 측정이 열쇠·값 | ① |
| 자기 vs 교차 Attention, 멀티헤드 | 같은 집합끼리 / 한 집합이 다른 집합을 읽음; 여러 개를 병렬로 | 누가 누구를 보는지가 배선 결정 | ① |
| 위치 인코딩 | 순서 신호 추가 | 시퀀스에는 필요, **집합에는 넣으면 안 됨** | ① |
| Transformer 블록과 정규화 위치 | Attention + MLP, 각각 잔차 + 층 정규화 | 사전 정규화(우리, nanoGPT) vs 사후 정규화(원 논문): 워밍업 필요 여부가 다름 | ① |
| 가우스 과정 → NP → ANP → CNP·TNP·Set Transformer | 함수 분포 / 학습된 함수 분포 / 평균 병목을 Attention으로 해결 / 변형들 | 우리 핵심 모델과 비교 대상 | ① / ② |
| VAE·ELBO·재매개변수화 | 확률적 잠재 변수와 하한 학습 | 잠재 경로 NP 학습; 연구 수준 | ③ |
| 강화학습 기초·MDP | 행동 → 보상, 정책·가치 | 실험 선택은 의사결정 문제 | ② |
| Era of Experience | 사람 판단이 아닌 환경 경험에서 보상 | 프로젝트의 방향(입장문이지 구조 명세 아님) | ① |
| 월드 모델·모델 기반 계획 | 행동의 결과를 예측하는 학습된 시뮬레이터로 미리 계획 | 우리 NP는 "실험실의 월드 모델"; LeCun의 JEPA와 구분 | ② |
| 설계 방법: 가설 → 부품 변경 → 절제 → 규모 확인 | Vaswani 표 3, ANP, ConvNeXt가 예시 | AI와 함께 쓰는 방법 그 자체 | ① |
| 버킹엄 π·기호 회귀·신경-기호 혼합·PINN | 차원 묶음 / 공식 탐색 / 신경망과 공식 결합 / 물리식 벌점 | 이 프로젝트의 기호 쪽 | ① / ② |
| Bitter Lesson vs 대칭 내장 | 계산으로 확장되는 일반 방법이 결국 이긴다 vs 대칭을 넣어라 | 쟁점(아래): (a) 데이터 형식의 대칭과 (b) 답에 대한 지식을 나눠 판단 | ② |
| 곁가지: CNN·풀링, RNN·LSTM, 인코더-디코더 | 격자·국소성 / 순환 기억 / 압축 병목 | 우리 코드엔 없음. RNN은 Attention의 필수 선수가 아님(Karpathy는 RNN 없이 GPT로 감) | ② |
| 알아만 두기: GNN, MoE, 확산 모델, NAS, 토큰화·사전학습·RLHF, 스케일링 법칙 | - | 우리 코드에 대응 부품 없음 | ③ |

| 공정한 비교 | 같은 데이터·예산·튜닝·시드 여러 개, 검증에서 결정, 시험은 한 번 | ① |

## 10. 출처끼리 엇갈리는 쟁점 (비판자 토론 판정)

| 쟁점 | 판정 |
|---|---|
| 배치 정규화가 "내부 공변량 이동"을 줄여서 작동하나 | **약화.** 2015 논문의 가설; Santurkar 2018은 "손실 지형이 매끄러워져서", d2l 8.5.6은 "이름이 부정확하고 원리는 미해결". 우리 모델은 층 정규화만 씀 |
| 불변성과 등변성은 같은 말인가 | **엄밀 구분이 맞음.** Goodfellow 9.2 정의; d2l 7.1의 표현은 느슨함 |
| Kaplan vs Chinchilla | **약화.** 둘 다 언어 모델 결과; 우리 규모에는 "고정 계산량을 크기와 스텝에 어떻게 나눌까"라는 질문만 옮김 |
| 사전 정규화 vs 사후 정규화 | **둘 다 실재.** 하나만 "Transformer 블록"이라 부르면 안 됨; 우리는 사전 정규화, 워밍업 없음, 마지막 층 정규화 없음(AE:113), 층 정규화 하나를 질의·맥락이 공유(AE:79) → 효과 미검증 |
| Bitter Lesson vs 대칭 내장 | **약화 후 분리.** 데이터 형식의 대칭(순서 불변)은 넣고, 답에 대한 지식(고정된 특징·문법)은 정체를 부를 수 있음(EXP-062) |
| 큰 배치는 일반화를 해치나(Keskar vs Goyal) | **약화.** Dinh 2017 반론; 매 스텝 새 세계를 뽑는 우리 설정과는 거리 있음 |
| 옵티마이저는 역전파 전인가 후인가 | **틀은 반박.** 경사하강 한 걸음은 먼저, Adam·스케줄은 역전파 뒤 |
| 미적분 전에 선형대수는 내적만 | **반박.** 1단은 선형대수 불필요, 2단은 행렬곱·전치·shape 필요 |

## 11. 공부 순서 (첫 단계 경로)

1. **코드 읽기 기초:** Python 기본기 → NumPy 배열·shape·브로드캐스팅 (MIT 6.100L 1-3강, R-017).
2. **1단 미적분:** 함수 → 지수·로그 → 도함수 → **연쇄법칙** → 손계산 역전파(micrograd, 3Blue1Brown). 선형대수 없이 가능.
3. **선형 모델:** 가중치·편향·손실·경사하강 한 걸음 → 선형·로지스틱 회귀 → 분류 손실(소프트맥스·교차 엔트로피).
4. **2단 수학:** 벡터·내적·행렬곱·전치·shape → 편미분·기울기 벡터 → 층 단위 역전파.
5. **신경망:** 뉴런 → 활성화 → MLP → 초기화 → 일반화·과적합·데이터 분리·누설 → 정규화 층·잔차 → Adam·스케줄.
6. **확률:** 가우스·NLL → 학습된 분산 → 우연적·인식적 불확실성 → 전분산 법칙 → 앙상블 → BIC·BMA·식별 가능성.
7. **구조:** 귀납 편향 → Deep Sets → Attention → Transformer 블록 → NP → ANP; 우리 코드 AE를 줄 번호와 함께 읽기.
8. **실무와 감사:** Karpathy 레시피, 절제 연구, 시드 간 변동, R-018 감사 질문 10개.
9. **둘째 단계:** 헤시안·테일러·볼록성, 고유값·PCA, 가우스 과정, 정보 이득, 강화학습, 월드 모델.

Karpathy Zero to Hero는 8강 합계 14시간 32분이다. 역전파만 4시간 이상이므로 "한 번에 끝나는 개념"으로 계획하지 않는다.

## 12. 이미 아는 것 건너뛰기 (한국 고교 대응, 원문 확인)

- **배웠을 수 있는 것:** 함수·그래프(중2, 공통수학2), 다항식·2×2 행렬 연산(공통수학1), 지수·로그·시그마(대수),
  극한·다항함수 미분·극값·정적분(미적분Ⅰ), 확률·확률분포·상관·추정(확률과 통계).
- **선택과목을 들었을 때만:** 연쇄법칙·eˣ와 ln x의 미분·이계도함수의 의미(미적분Ⅱ), 벡터·내적(기하),
  역행렬·행렬식(경제 수학), 전치행렬·경사하강법 소개(인공지능 수학).
- **주의:** 위 대응은 2022 개정 교육과정 기준이다. 2015 개정(수학Ⅰ·Ⅱ, 미적분, 확률과 통계, 기하)으로 배웠다면
  연쇄법칙은 "미적분"에 있었다. 학교에서 배운 계산과 머신러닝에서의 뜻(예: 기울기)은 다를 수 있으므로, 건너뛰기 전에
  각 개념의 "설계에서 왜 필요" 칸을 설명할 수 있는지로 확인한다.
- **고교에 없는 것:** 편미분 이후의 모든 미적분, n차원 행렬·랭크·고유값, 우도 이후의 모든 확률, 프로그래밍과 신경망 전부.

## 14. 조사 중 발견한 우리 코드의 후속 과제 (2026-11-17 처리 결과)

1. **고침** 시드가 편향 초기값을 고정하지 못함: `train()`이 모든 Linear의 가중치와 편향을 시드 생성기로 뽑는다.
   테스트 `test_same_seed_gives_identical_starting_parameters`.
2. **고침** 가중치 캐시에 설정이 없음: 파일명이 `attentive_np_seed{n}_{지문}.pt`가 되었다. 지문은 모델·학습 코드, 세계 샘플러,
   상수, 맥락 크기의 해시다. 기존 `attentive_np_seed{n}.pt`는 지우지 않았지만 더 이상 읽지 않으므로, `load_or_train`을 쓰는
   실험을 다시 돌리면 새로 학습한다(이전 결과는 편향 초기값이 무작위였으므로 원래부터 비트 단위 재현이 안 됐다).
3. **버그 아님** 전부 가려진 행: 사전 토큰이 항상 보이는 열쇠로 붙어(AE:106) 모든 Attention 행에 최소 하나의 열쇠가 있다.
   테스트 `test_hidden_measurements_do_not_change_predictions`로 고정.
4. **고침** 직접 구현 Adam을 `adam_step`으로 분리하고 PyTorch 공식 Adam(`torch.optim.adam.adam`)과 float64에서
   1e-12 이내로 일치함을 테스트(`test_adam_step_matches_torch_adam`).
5. **실험으로 확인(EXP-063): 함정 미미, 현재 손실 유지.** β-NLL 0.5·1로 바꿔도 평균 오차 비율 0.998(0.985-1.012).
   대신 학습 범위 밖 세계에서 90% 구간 포함률이 31-33%로 과신이 크다는 다른 문제가 드러났다.
