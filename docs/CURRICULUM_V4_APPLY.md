**E01: 약 12–18시간부터, 필요하면 연장.** 발췌·계약 2–3, 구현·로그 3–5, 재생과 재채점 2–3, 실패 귀속 2–3, 처음 보는 기록의 독립 설명과 수정 3–4시간. 정상과 실패 케이스 한 세트 뒤 새 ID·예산·실패 유형으로 두 번째 세트를 반복한다. 근거 있는 원인과 불명 판정을 모두 남기고, 연속 두 세트가 이진 기준을 충족하며 도움 없이 새 로그를 설명할 때 완료 표시한다. 검사를 놓치면 반례를 추가해 다시 시도한다.

## 호환 계약과 표시

- `learning-roadmap.mjs`의 본선 13개 `phase.id`는 `backend/learning-curriculum.mjs`의 폴더 키다. 기존 자료를 같은 단계·같은 상대 순서에 둔다. `lectureId` 공유 자료의 첫 번째 `resource.id`가 진행 키이고, 강의 헤더도 첫 일치 위치를 쓴다 (`learning-model.mjs`, `learning-ui.mjs`). v4 카드는 본선 배열과 분리하고 기존 다음 할 일·진행률·폴더 순서·강의 위치는 그대로 둔다. 추가 필수 카드는 별도 진행률·다음 과제로 표시한다.
- 일반 읽기/실습은 `resource.id` 자체가 키다. `/api/learning/progress`와 로컬 저장소·백업/동기화는 이 키를 이용한다. 기존 키·강의 ID·URL을 변경하거나 마이그레이션하지 않는다. 새 ID는 `v4-` 접두사, 새 영상 강의 ID는 이전 자료와 겹치지 않는다. 확인된 공개 404는 원 URL·권한 안내 및 자기 완료 조작은 남기고 접근 불가 사유를 표기한다.
- `learning-map-view.mjs`는 새 카드를 단계 끝에서 접어 표시하고, 대기 상태에서도 명세는 읽을 수 있게 한다. 단계 완료는 **앱 밖 직접 과제 확인 후 남기는 명시적인 자기 확인**으로 표시한다. 기존 읽기·강의 완료는 그 확인으로 간주하지 않는다. 실제 선수 카드만 완료 키로 제어한다. 실습 fixture·채점기·실행기는 이 PR 범위가 아니며 UI에 표시한다.
- 개념 지도 생성기와 JSON은 기존 개념·자료 ID를 유지한다. v4 선택 경로를 추가하더라도 v1 역사적 판정이나 숙달의 증거로 표시하지 않는다. 내부 과제는 로드맵으로 이동하고 선수를 확인한다.
- 자동 검사는 기준판의 익명 합성 진행 fixture로 기존 키, 학습 활동, 완료, 다음 할 일, 분모, 첫 2주, 강의 위치를 비교한다. 롤백은 v4 코드만 되돌리며, 저장된 신·구 기록은 삭제하지 않는다.
