# 여러 PC에서 같은 기록과 한국어 번역으로 공부하기

1. 두 PC에 Duvi를 설치하고 같은 강의와 영어 자막을 준비합니다. 처음에 강의 목록과 폴더까지 옮길 때는 **전체 백업**을 쓸 수 있습니다.
2. OneDrive처럼 자신만 접근하는 클라우드에 `Duvi-sync` 폴더를 만듭니다. 두 PC의 **학습 → 백업·동기화**에서 각각 그 폴더를 선택합니다. PC마다 전체 경로는 달라도 됩니다.
3. 공부를 마친 PC에서 **이 PC 기록을 동기화 폴더로 내보내기**를 누르고 클라우드 전송이 끝날 때까지 기다립니다.
4. 받는 PC에서 **다른 PC 파일 다시 찾기 → 합치기 전에 미리보기**를 누릅니다. 새 기록 수, 번역을 더하거나 교체할 강의 수, 건너뛴 이유를 확인합니다. 체크한 뒤 **확인한 내용으로 합치기**를 누르고 해당 강의를 다시 엽니다. 저장된 번역은 로그인이나 AI 호출 없이 읽을 수 있습니다.

## 무엇을 주고받나요?

| 파일 | 내용 |
|---|---|
| `duvi-sync-<기기ID>.json` | 질문·설명·수정 이력, 복습, 완료 표시, 질문하기 대화 |
| `positions/<기기ID>.json` | 강의별 이어보기 위치와 저장 시각 |
| `translations/<기기ID>/<강의ID>.json` | 그 강의의 한국어 번역, 문장 구분을 바꾼 경우 짝이 되는 영어 문장과 시각, 원본 확인용 정보 |

각 PC는 자기 파일만 씁니다. 바뀐 번역만 임시 파일에 쓴 뒤 완성되면 이름을 바꿉니다. 용량은 문장 수와 길이에 따라 달라집니다. 문장당 약 300바이트라면 500문장 강의 하나는 약 150KB입니다. 영상·강의 목록·계정 정보·로그·저장 전 초안·브라우저 기기 내 번역은 보내지 않습니다. 이 폴더의 내용은 암호화되지 않으므로 본인만 쓸 수 있는 폴더를 선택하세요.

## 두 PC에서 같은 내용을 바꾸면?

- **이어보기 위치**는 강의별로 더 최근에 본 위치를 씁니다. 10분까지 본 뒤 5분으로 돌아가 복습했다면 5분이 최신 위치입니다. 합칠 때 이 PC에서 재생 중인 강의는 건너뜁니다. 일시정지한 강의의 새 위치는 다시 열 때 적용됩니다. 저장 시각이 없는 예전 위치끼리는 이 PC의 값을 유지하고, 위치가 빠진 옛 파일도 가져올 수 있습니다.
- **처음 업데이트할 때** 기존 위치는 마지막으로 본 시각을 알 수 없어 가장 오래된 값으로 취급합니다. 상대 PC에 저장 시각이 있는 위치가 있으면 그쪽이 이깁니다. 두 PC의 시계를 맞춰 주세요. 보내거나 받는 PC의 서버 시각보다 5분 넘게 앞선 위치는 건너뜁니다. 이어보기 위치는 브라우저에 있어 `before-sync.json`에 들어가지 않습니다. 합치기 전 위치까지 보관하려면 **전체 백업**을 받아 두세요.
- **학습 기록**은 한쪽에서 이어 고쳤으면 그쪽을 씁니다. 양쪽에서 따로 고친 경우 나중 내용을 현재 값으로 쓰고 다른 쪽은 수정 이력에 남깁니다. 복습과 대화는 양쪽 내용을 합칩니다. 자료별 학습 상태는 더 나중 표시를 씁니다.
- **번역**은 영어 원본과 번역 방식의 버전을 먼저 확인합니다. 문장 구분까지 같고 기존에 번역한 문장을 모두 포함할 때만, 더 많이 번역한 쪽을 통째로 씁니다. 분량도 같으면 번역 저장 시각이 늦은 쪽을 씁니다. 문장 경계가 다른 두 번역은 섞지 않고 이 PC의 번역을 유지합니다.
- **원본이 없거나 파일이 손상된 경우** 해당 번역을 건너뛰고 이유를 보여 줍니다. 학습 기록은 합칩니다. 클라우드 전송과 양쪽 영어 자막을 확인한 뒤 다시 내보내기·가져오기를 하세요. 파일 해시는 손상을 확인하며 작성자의 신원을 보증하지 않습니다.
- 미리보기는 10분간 유효합니다. 확인한 뒤 번역이 바뀌면 이번에는 그 번역을 건너뜁니다. 합치기 직전 학습 기록은 `backend/learning/before-sync.json`, 교체한 강의의 직전 번역은 `backend/learning/before-sync-translations/<강의ID>.json`에 보관합니다.

## 파일을 나눈 이유

각 PC가 자기 기기 파일만 쓰면 두 PC가 같은 파일을 덮어쓰는 일을 피할 수 있습니다. 구버전 Duvi는 기록 파일의 필드를 엄격하게 확인합니다. 이어보기 위치와 번역을 별도 파일에 두면 한 PC만 업데이트해도 다른 PC에서 학습 기록을 계속 받을 수 있습니다.

Git 저장소나 Duvi 데이터 폴더 안은 동기화 폴더로 쓸 수 없습니다. **`backend/` 자체를 클라우드에 두지 마세요.** 두 PC가 임시 파일을 동시에 쓰면 완성되지 않은 파일이나 클라우드 충돌 사본이 생길 수 있습니다. Git으로 코드만 업데이트하고 개인 기록은 위 절차로 옮기세요.

## 확인 범위

한 컴퓨터에서 폴더와 포트가 다른 두 서버로 기록·번역·이어보기 위치를 주고받았습니다. 물리적인 PC 두 대와 OneDrive의 실제 전송 지연·파일 잠금은 확인하지 않았습니다. [브라우저 확인 기록](qa-evidence/2026-11-22-translation-sync/README.md)
