# 전체화면 학습 화면 정리 — 세 시안 (2026-11-23, 선택 전)

사용자 요청: "강의창에 기록 기능은 없애면 되고 나는 질문하는게 자동으로 질문으로 가졌으면 좋겠어", 전체화면이 "더 정갈 했으면". 사용자 스킬 task-first-frontend(2026-11-23 수정본)를 따랐다. **구현 전 시안이며, 사용자가 고르기 전에는 구현·병합하지 않는다.**

## 1. 과업

1. 영상을 보다가 막히면 바로 질문한다(지금 시각이 붙는다).
2. 보낸 질문은 따로 "기록으로 저장"을 누르지 않아도 내 기록(열린 질문)이 된다.
3. AI 답 아래에 내 설명을 쓰고, 어떤 질문이 아직 열려 있는지 본다.
4. 대본으로 앞 문장을 확인하고 그 시점으로 이동한다.

## 2. 비포 (현재 화면, 같은 강의·같은 폭)

| 파일 | 상태 |
|---|---|
| `before/before-fs-1536.webp`, `before-fs-1280.webp` | 전체화면, 패널 닫힘 |
| `before/before-fs-1536-chat.webp`, `before-fs-1280-chat.webp` | 질문하기 탭 |
| `before/before-fs-1536-record.webp`, `before-fs-1280-record.webp` | 기록 탭 |
| `before/before-normal-1536-chat.webp` | 일반 화면 질문하기 |

현재 화면에서 본 문제(1536 질문하기 기준):
- 영상 위 조작이 **두 줄**(문장 이동 3, 위치, 자막 크기, 자동 멈춤, 속도, 강의 완료, 질문하기, 대본, 나가기).
- 패널 본문 전에 **조작 세 줄**: 탭 4개(대본·질문하기·기록·학습)+닫기 / 제목+필터 3개 / 모델 선택+보낼 때 멈추기+새 대화.
- "대본"이 탭과 필터에 **중복**. 모델 선택·보낼 자료·두 줄 안내문이 **항상** 보임.
- 질문을 기록으로 남기려면 "기록으로 저장"을 눌러야 하고, 편집은 별도 "기록" 탭.

## 3. 세 시안 (공통: 기록 탭 없음, 보낸 질문은 자동 기록, 모델·보낼 자료는 ⋯ 안으로)

| | A 옆 패널 한 줄 정리 | B 영상 위 떠 있는 질문 카드 | C 대본 안에 질문이 달리는 목록 |
|---|---|---|---|
| 구조 | 영상 + 오른쪽 380px 패널(질문 \| 대본) | 영상 전체 폭, 질문할 때만 오른쪽 아래 카드 | 영상 + 오른쪽 패널 하나(대본과 질문을 한 목록) |
| 패널 머리 | 한 줄: 질문·대본 전환 + 닫기, 아래 필터 2개 | 카드 제목(지금 시각 근처) + 전체 목록 ☰ + 닫기 | 한 줄: 제목 + 모두/질문만 + 닫기 |
| 질문 기록 | 카드에 ○열린 질문·자동 기록됨 / ●내 설명 있음 | 같음, 단 지금 근처만 | 그 문장 바로 아래 들여 쓴 질문 |
| 영상 크기 | 패널만큼 좁아짐 | 가장 큼(카드가 영상 일부를 가림) | 패널만큼 좁아짐 |
| 강점 | 지금 화면과 가장 가까워 바꿀 양이 적음 | 영상 몰입, 화면이 가장 비어 보임 | 질문이 어느 문장에서 나왔는지 바로 보임 |
| 약점 | 대본과 질문을 오가려면 전환 필요 | 전체 질문을 보려면 한 단계 더, 슬라이드 일부 가림 | 대본이 길면 질문이 묻힘(질문만 필터 필요) |

이미지: `alts/alt-{a,b,c}-{1536,1280}.webp`. 원본 HTML 시안: `alts/mock.html#a|b|c`(예시 내용, 실제 데이터 아님).

검사(Bun.WebView, 1536×864·1280×800 뷰포트): 여섯 장 모두 `scrollWidth == innerWidth`, 패널·카드·입력창·자막·시간 띠·조작 줄이 화면 밖으로 잘린 요소 0개.

## 5. 조사하지 못한 것

- Refero·Nicelydone(유료), Pttrns(가입 필요), Page Flows(플레이어 화면 유료 체험) — 방문했지만 볼 수 없음. Mobbin 무료 계정은 검색당 2화면이라 Vimeo 1장만 사용.
- Coursera·Udemy·edX·LinkedIn Learning·MasterClass·Skillshare·Netflix·Disney+는 수강·결제·로그인 없이 랜딩 화면까지만. Khan Academy는 기부 안내 화면이 영상을 가려 제외.
- 조작 줄이 자동으로 숨는 상태는 캡처하지 못함(에이전트 창에서 영상이 재생되지 않음). 선택 후 구현 단계에서 실제로 확인한다.
- 사람이 직접 써 본 비교(시간·실수)는 하지 않았다. 시안 비교는 배치 차이까지만 말한다.

## 6. 정해 주실 것

1. A·B·C 중 하나(또는 섞기).
2. 질문을 모두 자동 기록할 때, 내 설명을 쓴 질문만 복습에 넣을지(권고: 예).
3. 기록 탭에 있던 세부 칸(관측·가정·예측·결과·생각 수정, AI 튜터)을 "내 기록" 창으로 옮길지(권고: 예).
