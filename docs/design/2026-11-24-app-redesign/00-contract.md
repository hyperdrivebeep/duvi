## 이상 상태

- 강의 화면이 앱의 중심이다. 영상과 두 줄 자막은 어떤 패널을 열어도 잘리거나 가려지지 않는다.
- 질문은 보내는 순간 기록이다. "기록으로 저장" 단계가 없고, 기록 편집은 그 질문 자리에서 한다.
- 확인 문제, 개념, 진척도는 강의 화면에서 한 번의 행동으로 닿고, 닿았다가 같은 시각으로 돌아온다. 영상 재생 인스턴스를 다시 만들지 않는다.
- 개념 지도는 위(큰 주제)에서 아래(선수 개념)로 읽히고, 자료가 없는 개념은 빈 곳으로 보인다.
- 진척도는 두 가지를 섞지 않는다: 내가 완료로 표시한 것, 기록·문제·커밋이 보여 주는 것.
- AI가 쓴 것은 항상 "AI 제안"으로 표시한다. 시청 시간·자기 표시·AI 판정은 숙달을 인증하지 않는다.
- 상태는 글자와 모양으로 구분한다. 색만으로 구분하지 않는다. 강조색은 주 행동과 현재 위치에만 쓴다.

## 지킬 기능 약속과 바꾸는 결정

- 지킨다(`_discovery.md` 6.2): 영한 문장 쌍과 표시 단위 이동·반복, 최초 설명·수정·복습 이력 보존, AI는 요청할 때만·"제안" 표시, 숙달 자동 인정 없음, 학습 기록은 이 PC에만, 완료는 명시적이고 되돌릴 수 있음, 학습자 코드를 앱이 실행하지 않음, 외부 저장소에 자동으로 올리지 않음, 재생 인스턴스 유지.
- 바꾼다(사용자 요청 2026-11-23·24): 질문은 "기록으로 저장" 없이 자동으로 질문 기록이 된다(AGENTS.md:69 변경). 기록 탭을 없앤다. 왼쪽 강의 목록·파랑/흰색·패널 구조 같은 배치와 색은 새로 정한다.
- T2·T4의 저장소 연결은 읽기 전용이다(로컬 저장소의 파일·커밋 기록·테스트 결과 파일을 읽기만 함). 코드 실행과 push는 하지 않는다.

## 미확인 가정

- 학습자의 실제 사용 빈도, 막히는 지점, 과업 우선순위는 관찰하지 않았다.
- 개념→강의 대응 데이터와 저장소·위키를 읽는 경로는 설계 가정이며 구현 가능성은 확인하지 않았다.
- 시안은 정적 그림이다. 키보드, 확대, 스크린리더, 실제 재생 연속성은 시안 단계에서 검증하지 못한다.
