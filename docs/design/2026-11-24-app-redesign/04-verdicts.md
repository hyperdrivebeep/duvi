# 가드레일·검증 판정 (S5) — Duvi 앱 전체 재설계

판정 대상: 세 시안(정적 HTML 목업, `03-alts/mock.html`을 1536×864와 1280×800으로 렌더한 14장)과 비포 캡처 14장. 시안은 제품에 연결되지 않은 그림이다. 키보드, 확대, 스트리밍, 저장, 복귀를 실행하지 않았으므로 동작이나 측정이 필요한 규칙에는 PASS를 주지 않고 UNVERIFIED로 두었다. 조건이 제품에 없을 때만 N/A다. scope가 design-only라서 이 UI는 **미검증** 상태다.

범위 밖: `rules-components.md`, `rules-inputs.md`, `rules-technologies.md`와 검증 묶음의 참고 문서(UI-01~UI-08)는 읽지 않아 C-/I-/T-/UI- 행이 없다. 구현 단계(S6)에서 읽고 판정한다.

시안에서 스크립트로 확인한 것(PASS 근거가 아니라 참고): 14장 모두 가로 넘침 0, 화면 밖 요소 0, 잘린 글자 0(`mock.html`의 점검 스크립트, headless Chrome). 글자 크기 CSS 최솟값 14px.
