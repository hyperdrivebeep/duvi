## 확인한 것과 확인하지 못한 것

- 스크립트 점검(headless Chrome, 14장): 가로 넘침 0, 화면 밖 요소 0, 잘린 글자 0. CSS 글자 최소 14px.
- 단계 게이트(task-first-frontend `gate.mjs --stage 5`): `RESULT: PASS (S0..S5: 28 PASS, 0 FAIL, 1 WARN, 1 INFO, 0 N/A)`. 전체 출력은 [gate-stage5.txt](gate-stage5.txt).
- 레퍼런스: 사이트 목록의 14곳 중 13곳 방문, 1곳(Pttrns)은 계정 생성이 필요해 건너뜀. 캡처 74장. 화면 모음 사이트 캡처와 출처 보드 이미지는 유료 사이트 화면을 담고 있어 이 공개 저장소에 올리지 않았다(출처 표는 [provenance.md](provenance.md)).
- **미검증**: 키보드, 200% 확대, 스크린리더, 대비 측정, 실제 재생·스트리밍·저장·복귀, 빈 상태와 오류 화면. 판정표의 필수 행 대부분이 UNVERIFIED다. 전체화면 화면은 이번에 따로 그리지 않았다.
- 화면 모음 사이트는 모두 무료 등급이라 연속 흐름을 거의 보지 못했다. 개념 지도와 "질문 자동 기록"을 그대로 하는 출시 화면은 찾지 못했고, 여러 화면의 원리를 조합한 가설이다.
- 사용자 조사나 사용성 시험은 하지 않았다. 어느 시안이 더 나은지는 측정하지 않았다.
